# Gestion d'archives (Laravel)

Application web de gestion d'archives et de documents avec suivi des emprunts et des retours, développée avec Laravel et MySQL.

## Fonctionnalités
- Gestion des documents, des divisions, des emplacements et des statuts
- Gestion des emprunts et des retours de documents
- Suivi des dates et détection des retards

## Technologies
Laravel, PHP, MySQL, HTML, CSS

## Lancer le projet
1. Cloner le dépôt
2. Exécuter `composer install`
3. Copier `.env.example` vers `.env` et configurer la base de données
4. Exécuter `php artisan key:generate`
5. Exécuter `php artisan migrate`
6. Exécuter `php artisan serve`

## Remarque
Les données utilisées sont fictives.
